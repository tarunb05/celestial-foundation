# The Celestial Foundation — website

Registered non-profit for education & social development, Bangalore.

- **Stack:** Vite, Three.js (hero moon + particle sea, 3D project orbit), GSAP ScrollTrigger, Lenis smooth scroll.
- **Content:** `src/data.js` (projects, moments, contact intents). Photos live in `public/img/`.
- **Contact:** WhatsApp / call +91 63607 71754, volunteer Google Form.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # outputs dist/
```

Deployed on Vercel (framework preset: Vite).
